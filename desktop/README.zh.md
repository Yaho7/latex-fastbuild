# Texgo 桌面版

Texgo 桌面版使用 Tauri 2、Rust 和 React，面向 Windows、macOS 和 Linux。它在本机扫描 LaTeX 项目、转换引用到的图片，并更新对应的 TeX 引用；项目内容不会上传到服务器。

## 使用流程

1. 打开项目根目录中的 `.tex` 主文件。
2. 检查扫描到的图片、章节、引用位置和未解析路径。
3. 选择需要转换的图片以及质量，执行转换。
4. 比较原图和生成的 PDF，打开“预览替换”检查路径差异。
5. 应用替换。需要恢复时，使用“撤销替换”。

原始图片保留。生成的 PDF 放在原图片目录的 `texgo-pdf/` 内，文件名包含源文件内容和转换参数的摘要，避免同名覆盖。已有 PDF 直接复用，不重复转换。

## 图片质量

| 模式 | 行为 |
| --- | --- |
| 原始 | 保留位图像素，使用无损图像流 |
| 高质量 | 按 160 mm 目标宽度限制到 300 PPI，不放大原图；不透明图片使用 JPEG 质量 92 |
| 紧凑 | 按 160 mm 目标宽度限制到 150 PPI，不放大原图；不透明图片使用 JPEG 质量 75 |
| 自定义 | 设置目标 PPI、排版参考宽度和 JPEG 质量 |

透明位图保留透明通道，并使用无损图像流。SVG 优先保留矢量；带滤镜的对象可能被转换库局部栅格化。SVG 的字体外观依赖系统字体是否可用。

转换会读取 PNG 的物理尺寸标记、JPEG 的 JFIF 密度或 EXIF 分辨率，以保留自然页面尺寸；无有效密度时使用 72 PPI。质量选项中的参考宽度用于决定降采样的像素上限，不改变 PDF 页面尺寸。TeX 自定义分辨率命令等特殊设置仍需人工核对。改变 DPI 数值不能增加原图细节。

支持 PNG、JPEG、WebP、TIFF、BMP、GIF 和 SVG。GIF/TIFF 等多帧或多页输入只处理解码器默认的第一帧或第一页，不生成动画。EPS/PS 暂不转换。

## 引用识别与替换

- 递归识别 `\input`、`\include` 和 `\subfile`。
- 识别 `\includegraphics`、星号形式、可选参数和 `\graphicspath`。
- 忽略注释、常见逐字环境和 `\verb` 中的示例代码。
- 多个同名文件、宏生成路径、缺失资源会标记出来，不猜测替换。
- 主文件所在目录作为项目根目录。根目录之外的 TeX 和图片不会自动处理。
- 源文件要求 UTF-8；替换只修改路径位置，保留其余文本和换行。

这不是完整的 TeX 解释器。复杂条件、局部作用域、自定义图片宏及动态搜索路径需要人工确认；第一版也不执行 LaTeX 编译、SyncTeX 或自动编译。

## 撤销与冲突

应用前和撤销前会检查文件当前内容，避免覆盖编辑器里已经保存的新修改。单次最近替换的备份保存在项目的 `.texgo/undo.json`，关闭应用后仍可撤销。重复应用新的替换会更新最近一次备份。

若批量替换中途失败，恢复记录保留；重新打开项目后可以撤销已完成部分。不要删除 `.texgo/` 后再尝试恢复。当前转换任务取消时，会先完成正在处理的那张图片，再停止后续任务。

## 下载与发布

GitHub Actions 负责全部测试、编译和打包，本地工作流只修改源代码。

- 普通分支和 PR：执行前端检查、测试、三系统 Rust 测试及安装包构建，产物保存在 Actions。
- `desktop-v*` 标签：检查版本一致性，等待全部平台打包成功后发布到 GitHub Release，附带 SHA256 校验文件。
- 桌面版标签与现有 CLI 的 `v*` 标签分开。

首批目标为 Windows x64、Linux x64、macOS Apple Silicon 和 Intel。未配置开发者证书时，Windows 包未签名，macOS 包只有临时签名，系统可能显示安装警告；当前发布不代表已完成各平台真实安装验证。

详细发布说明见 [desktop-release.md](../docs/desktop-release.md)，CI 说明见 [README.md](README.md)。
